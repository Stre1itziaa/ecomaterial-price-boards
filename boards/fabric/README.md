# fabric-price-tracker 电子布(玻纤布)价格证据看板

跟踪 2026 电子布涨价周期的核心品类价格证据:7628 厚布 / 1080·2116 薄布 /
Low-Dk 二代布 / G75 电子纱 / FR-4 覆铜板 / HVLP 铜箔,外加四家 A 股布厂公告流。
与 mlcc-price-tracker / storage-price-tracker 同一套管线架构
(抓取 → SQLite → 审计 → 看板 → schtasks),端口 8793。

## 快速使用

```bash
python -m tracker.update            # 公告流增量 + 锚点 seed + 导出(约 30 秒)
python -m tracker.update --no-crawl # 跳过抓取,仅重导出
python -m tracker.audit             # 数据审计(交付前必跑,FAIL 即不可信)
python serve.py                     # 看板 http://127.0.0.1:8793
```

依赖:`requests`

## 已知边界(诚实声明,先读这个)

- **本板没有连续价格曲线,这是设计而非缺陷**:电子布是中间材料——
  零售分销渠道无 SKU(云汉搜"电子布 7628"实测 302 重定向)、卓创/百川现货库
  为付费源、TWSE 台股月营收通道 2026-09-23 实测被本机出口拦截
  (直连与 Playwright 均返回 800B 安全壳页,待换通道接入)。
  按"历史必须真实"红线,免费公开源下只入库**带公开出处的价格锚点**,
  绝不插值造曲线。
- **PDF 正文不解析**:公告流只到标题+日期+链接;公告里的价格数字经人工核验
  后才进锚点层(`tracker/news_anchors.py`),机器不自动提取,防止口径错读。
- **锚点口径分列绝不混算**:工厂出厂价/经销商报价/市场成交价/公司财报口径/
  原厂合约调价各成系列;主图中同口径才连线,跨口径对比须核对口径列。
- 无公开出处的数字(如各卖方缺口测算"40%""70%")不入库。

## 审计(交付前必跑,当前 10 项)

1. 锚点无未来日期;出处/口径/数值非空;主数值为正;
2. 锚点口径全部在白名单(parts.CALIBERS,10 项);
3. 品目覆盖 ≥4;价格类锚品目必须在 6 品目清单内(交期类不限);
4. 同口径主数值时序非递降(递降是合法周期信号 → WARN 展示,不 FAIL);
5. 公告流四家公司在库;最新披露 ≤15 天(在线性代理);
6. 重要公告(调价/经营数据/定期报告/扩产)≥5 条。

  周期区间(格式 **YYYYMMDD-MMDD**,如 20260918-0924,期末为该周锚)

### 候选核验 SOP(2026-10-11 成文)

核验验证的是**传播链一致性**,不是数据真实性——公众号抄卓创,卓创原始库在付费墙里,
你永远无法直接对照源头。因此:

1. **原文可打开**:微信链接可访问,正文与候选摘要一致(防搜狗缓存错位);
2. **数字抄写复核**:候选表的"数字片段"与原文逐字对照(机器抽取带噪声);
3. **口径可判定**:能明确归入口径白名单;判不清 → 只入涨幅锚、不入绝对值;
   连涨幅都存疑 → 已否决。

**准入规则**:绝对价格需 ≥2 家独立转引互证;涨幅类单源可收。
锚点现带 **grade 来源分级徽章**(一手公告 > 主流媒体 > 公众号转述),
看板一眼可见每条数字的证据硬度;来源分级随 anchors 表 grade 列入库。
